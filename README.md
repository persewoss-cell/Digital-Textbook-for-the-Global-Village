# 🌍 지구마을 디지털 교과서

3~6학년 "지구마을" 시리즈를 위한 디지털 교과서 웹앱입니다. 계정(아이디/비밀번호) 가입 없이,
**선생님이 반마다 비밀번호로 잠긴 "방"을 만들고, 학생은 이름·번호·그 비밀번호로 들어오는** 아주 단순한
구조예요. React + Firebase(무료 Spark 요금제)로 만들어졌습니다.

## 사용 흐름

1. **선생님**: 첫 화면에서 "방 만들기"를 눌러 학년/반, 자기 이름, 4자리 숫자 비밀번호를 정해요.
   그러면 방이 하나 생기고, 첫 화면에 학년·반 순서로 정렬된 사각 박스로 표시돼요. 이 비밀번호는
   **선생님이 관리 화면에 들어갈 때만** 쓰고, 학생에게는 보이지 않아요.
2. **학생**: 첫 화면에서 자기 반 방을 찾아 "학생 참여하기"를 누르고 번호·이름만 입력하면(비밀번호
   없이) 바로 그 학년의 디지털 교과서로 들어가요.
3. 학생이 교과서에서 한 필기·메모·진도는 **그 방이 삭제되기 전까지** 계속 남아있고, 같은 방에
   같은 번호로 다시 들어오면 이어서 볼 수 있어요.
4. **선생님**은 방 박스의 "선생님" 버튼(비밀번호 입력)으로 들어가면, 반 학생들이 **지금 보고 있는
   쪽을 실시간 썸네일 카드**로 볼 수 있어요(4개씩 배열, 번호·이름 표시). 카드를 누르면 그 학생의
   화면을 그대로 열어 직접 페이지를 넘기며 확인할 수 있어요. 방을 다 쓰면 "방 삭제하기"로 없앨 수
   있어요.
5. **관리자**는 첫 화면의 "관리자" 링크에서 **마스터 비밀번호(기본값 7279)**를 입력하면, 개별 방
   비밀번호를 몰라도 모든 방을 열람/관리할 수 있고, 교과서 등록도 이 화면에서 해요.

## 디지털 교과서 뷰어 기능

- 화면에 꽉 차게 자동으로 맞춰지는 **두 쪽 보기 / 한 쪽 크게 보기**, 확대·축소
- 왼쪽 **목차** 패널(단원별로 바로 이동) — 관리자 화면에서 "자동으로 후보 찾기"로 목차 초안을 뽑을 수 있음
- 가운데 하단에 떠 있는 **쪽 넘기기 / 쪽 번호 바로가기** 바
- 펜/형광펜(색상 선택) + **지우개(크기 조절)** + **실행취소/다시실행**
- **노트 도구**: 교재의 빈 곳을 클릭하면 오른쪽 노트 패널에 입력칸이 생기고, 타이핑하면 그 자리에
  맞는 글씨 크기로 자동으로 들어가요
- 교재 내 **검색**(실제 PDF 텍스트 기반, 결과 클릭 시 이동)
- 현재 쪽을 필기와 함께 **이미지로 캡처 저장**
- 학습 진도 자동 기록(마지막 읽은 쪽)
- 선생님/관리자가 학생 화면을 열람할 때는 **읽기 전용 모드**로 동일한 필기/노트를 볼 수 있음

## 기술 스택

- React 18 + TypeScript + Vite + Tailwind CSS, React Router
- Firebase Auth(**익명 인증만** 사용, 로그인 화면 없음) / Firestore — **Cloud Functions, Storage 없음**
- pdfjs-dist(PDF 렌더링) — 페이지 넘김/필기 레이어는 자체 구현(외부 "책 넘김" 라이브러리 없이
  화면 크기에 맞춰 스스로 배치하도록 만들었어요)

### 교과서 PDF는 어디에 저장되나요?

Firebase Storage(파일 저장 서비스)는 2024년 10월부터 **무료 Spark 요금제에서 아예 쓸 수 없게**
바뀌었어요(버킷 생성 자체가 유료 Blaze 요금제 전용). 그래서 이 프로젝트는 Storage 대신, 교과서
PDF 파일을 `public/textbooks/{학년}/` 폴더에 직접 넣어두고 **Firebase Hosting이 정적 파일로
그대로 서빙**하도록 만들었어요. Hosting은 Spark 요금제에서도 완전히 무료예요.

## 왜 이렇게 설계했나요? (중요 — 보안 수준 안내)

Firebase의 Cloud Functions(서버 코드)는 무료 Spark 요금제에서 아예 쓸 수 없어요. 그래서 이 앱은
서버 없이 브라우저(클라이언트)만으로 동작하도록 만들었고, 그 결과:

- 방 비밀번호와 관리자 마스터 비밀번호는 **클라이언트에서 직접 비교**해요. 암호화된 진짜 보안이
  아니라, "코드를 몰라서 못 들어오는" 정도의 가벼운 잠금이에요. 개발자 도구로 Firestore 요청을
  직접 들여다보면 이론적으로 우회할 수 있어요.
- Firestore 보안 규칙도 "우리 앱을 거쳐 들어왔는지(익명 인증 여부)"만 확인하고, 그 이상 세밀한
  권한 구분은 하지 않아요.
- 이 정도 수준은 같은 학교 안에서 낮은 위험도의 학습 자료(개인정보 없음, 이름+번호 정도)를 다루는
  용도로는 충분히 실용적이지만, 진짜 개인정보나 민감한 데이터를 다룬다면 적합하지 않아요. 나중에
  더 강한 보안이 필요해지면 Blaze 요금제 + Cloud Functions로 확장할 수 있어요.

## Firebase 프로젝트 설정 방법

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 새 프로젝트를 만듭니다 (무료 Spark 요금제 그대로 사용 가능).
2. **Authentication** → 로그인 방법에서 **익명(Anonymous)**을 사용 설정합니다. (이메일/비밀번호는 필요 없어요)
3. **Firestore Database**를 만듭니다 (규칙은 이 저장소의 `firestore.rules`를 배포하면 됩니다).
4. **Storage는 만들지 않아도 됩니다** (무료 요금제에서 지원되지 않고, 이 프로젝트는 쓰지도 않아요).
5. 프로젝트 설정 > 일반 > 내 앱에서 웹 앱을 추가하고, 표시되는 설정 값을 `.env` 파일에 채워넣습니다 (`.env.example` 참고, `storageBucket` 값은 필요 없어요).
6. `.firebaserc`의 `REPLACE_WITH_YOUR_FIREBASE_PROJECT_ID`를 실제 프로젝트 ID로 바꿉니다.

```bash
npm install -g firebase-tools   # 아직 없다면
firebase login

npm install                     # 의존성 설치
cp .env.example .env            # 값 채워넣기 (마스터 비밀번호도 원하면 여기서 변경)

firebase deploy --only firestore:rules
npm run build
firebase deploy --only hosting
```

## 로컬 개발

```bash
npm install
cp .env.example .env   # Firebase 웹 설정 값 채우기
npm run dev
```

## 교과서(PDF) 등록 방법

Storage를 쓰지 않기 때문에, PDF 파일 자체는 관리자 화면에서 업로드하는 게 아니라 **프로젝트
파일로 직접 추가**해야 해요.

1. `public/textbooks/{학년}/` 폴더에 PDF 파일을 넣습니다 (예: `public/textbooks/3/book1.pdf`).
   Claude에게 채팅으로 파일을 보내면 대신 추가하고 재배포해 줄 수 있어요.
2. `/admin`에서 마스터 비밀번호(기본 `7279`, `.env`의 `VITE_ADMIN_MASTER_PASSWORD`로 변경 가능)를 입력합니다.
3. "교과서 관리" 탭에서 PDF 파일을 한 번 선택하면(업로드되지는 않고, 쪽수만 자동으로 읽어와요)
   학년/과목/제목과 함께 **1번에서 넣은 것과 같은 파일 이름**을 입력하고 "등록하기"를 누릅니다.
4. 등록된 교과서의 "목차 관리"를 눌러 단원 제목과 시작 쪽 번호를 등록하면 왼쪽 목차에 표시됩니다.

## 프로젝트 구조

```
src/
  pages/
    RoomLobbyPage.tsx        # 첫 화면: 방 목록(학년/반 오름차순)
    CreateRoomPage.tsx       # 선생님: 방 만들기
    StudentJoinPage.tsx      # 학생: 번호/이름/비밀번호로 방 참여
    RoomManagePage.tsx       # 선생님: 방 비밀번호 재입력 후 학생 진도 모니터링, 방 삭제
    AdminMasterPage.tsx      # 관리자: 마스터 비밀번호, 전체 방 목록 + 교과서 등록
    TextbookViewer/          # 책 뷰어 (툴바, 목차, 노트, 필기 레이어 등)
  lib/
    rooms.ts                 # 방/참가자 생성·조회·삭제
    session.ts                # 익명 인증 부트스트랩, 방 잠금 해제 상태(sessionStorage)
    firestore.ts, pdf.ts
  types/
public/textbooks/{학년}/    # 교과서 PDF 파일 (Firebase Hosting이 정적 파일로 서빙)
firestore.rules / firebase.json
```

## 설계 메모

- 학생의 "계정"은 없고, `방ID_번호` 조합이 그 학생의 필기/노트/진도를 구분하는 키예요. 같은 방에
  같은 번호로 다시 들어오면 이전 기록이 이어집니다.
- 방을 삭제하면 그 방과 관련된 모든 필기/노트/진도 기록이 함께 삭제돼요(되돌릴 수 없음).
- 교재 PDF는 별도 이미지 변환 없이 `pdfjs-dist`로 브라우저에서 직접 렌더링합니다.
